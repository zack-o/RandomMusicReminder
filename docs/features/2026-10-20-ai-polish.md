# 0.6 AI 连接修复与界面完善

交付：兼容 DeepSeek 根地址的 Debug APK；明确的连接诊断；更易用的 AI 工作台和提醒首页。保持包名、Room 4、已有数据与现有依赖，不扩大到语音或图片识别。

## 连接约定

- 根地址和以 `/v1` 结尾的基础地址补全 `/chat/completions`；完整及自定义路径原样保留。发送确认页展示实际请求地址，不改变主机、不跟随重定向、不自动重试。
- DeepSeek 预设填写根地址、deepseek-flash、max_tokens；保持通用自定义入口。旧配置无需重填密钥。
- 错误按地址、认证、余额、参数、限流、网络和返回格式分类。只显示安全的错误代码与本地建议，不回显服务端原始正文、认证头或用户密钥。
- 手机现有密钥只由应用读取，测试使用合成输入，不发送现有任务及个人数据，不落盘明文。真实 API 测试必须显式传入开关，默认跳过。

## 界面设计

以时间和待办为主角，而非通用聊天页。颜色沿用森林绿 #356859、薄荷 #B8F0D8、雾白 #F7FAF7、石墨 #1B211E，警告用琥珀 #755B2B。使用系统中文无衬线：时间 40sp、页面标题 26sp、正文 15sp、辅助文字 12sp。无需下载字体。

```
提醒首页                    AI 工作台
日期 / 已启用数量           标题 / 管理连接
主要时间与提醒列表          主机、模型、连接检测状态
时间 | 标题、重复、下次      安排输入 + 示例 + 生成草稿
     | 提醒方式 / 次要试响   草稿 / 清晰错误 / 统计工具
```

内容左对齐。主要时间是视觉重点；少用同形卡片，不添加装饰渐变和自动动画。AI 配置使用全屏编辑页，普通设置和高级参数分组；底部保留取消与保存操作，键盘出现不遮挡。原始枚举、位掩码改为中文日期和星期。首页提供 AI 快捷入口，顶栏减少重复图标。

验收：地址及安全规则 JVM 回归；固定响应 HTTP 与界面设备测试；已有测试和 Lint、APK 构建；授权真机覆盖安装前备份 APK 与私有数据、全程无声；真实连接和合成任务识别分别说明结果，失败不假称通过。
