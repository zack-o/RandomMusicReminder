# 乐醒 0.4 小功能规格

## 范围与约束

- 单应用模块，Kotlin/Compose/Room/DataStore/Media3；不增加依赖，不联网，不操作手机，不改系统音量，不复制 E:\Music 整库。
- 保留现有未提交代码及用户数据库。修改前源码副本位于 `build/change-backups/2026-10-20-small-tools/`，不自动提交或推送。
- 音乐：搜索、状态筛选、名称/时长/大小/导入时间排序；明确勾选后批量启停；导入显示逐文件进度及失败明细，不增加批量删除。
- 试听：默认 5 秒/5% 应用内音量；可自定义 1～300 秒、0～100%、起点 0～86400 秒；参数持久化；超出曲长报错，离开前台或页面停止。
- 本地统计：主界面可见会话次数与单调时钟累计时长，按日期显示；配置变更不新增会话；可关闭，不回溯旧使用时长。响铃分析来自历史，试响单列，不将停止解释为任务完成。
- 节假日：用户已选择中国大陆官方放假＋调休补班；每事件 NONE/SKIP_OFFICIAL_HOLIDAYS/MAINLAND_WORKDAYS。按事件日期判定，提前提醒整体跟随事件。仅工作日模式替代每周星期选择；未知年份恢复原重复规则并提示。
- 官方日历只收录已核对的年份，不按农历公式推算未来放假和补班。
- 市场调研基于官方页面、注明核查日期和未核实能力，不声称实际安装或完整覆盖所有竞品。

## 界面方案

延续现有主题：主绿 #356859、浅绿 #B8F0D8、背景 #F7FAF7、次文字 #54645D、强调色 #755B2B；系统中文无衬线字体，标题/正文/辅助说明三级字号。

音乐页左对齐，上部为操作区，下部保留歌曲列表：

```text
音乐库数量 / 导入入口
搜索框
状态筛选 / 排序
试听参数 / 批量选择工具
导入进度或结果明细
歌曲列表（勾选、试听、名称信息、启用、移除）
```

统计从顶栏进入，保留底部三导航。以数据口径和日期明细为主，不添加装饰性图表；空数据明确说明从升级后开始记录。事件编辑器在重复规则旁提供节假日策略、覆盖年份和降级说明。
