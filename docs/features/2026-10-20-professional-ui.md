# 0.7 专业规则与统一交互

## 范围与边界

保留包名及现有单模块；不升级或新增依赖。不操作真机、不发声、不使用真实 AI。交付源码、中文文档、Debug APK和可执行的离线测试。数据库仅增加列，保留旧数据；JSON 导出升级版本 2，读取兼容版本 1。

## A. 提醒编辑与规则

- 编辑器为全屏工作区，顶部固定“基本 / 重复 / 提醒点 / 音乐”标签，底部固定保存与取消，每区单独滚动，不再一页堆叠所有参数。
- 重复增加 MONTHLY、YEARLY、INTERVAL；INTERVAL 为从开始日期按日历日每 N 天（1～3650），不是每 N×24 小时。所有重复支持可选结束日期，含当天。
- 月/年以开始日期锚定日号，缺少该日期可选跳过或取当月最后一天，默认跳过；不累积月底截断误差。年重复是公历，不宣称农历。
- 提醒点用紧凑摘要列表，逐项打开独立参数编辑；提前量用整数＋分钟/小时/天；1～32 个唯一偏移，提前最多 3650 天；响铃 5～1800 秒，保留稍后开关与 5/10/15 分钟。
- 法定工作日策略只替代每日/每周的星期限制；月/年/间隔规则不应被扩展到每天，假期只过滤这些规则的候选日期。

## B. 导航、主题与日历

- 四个主页面提醒、音乐、日历、设置使用 Pager，滑动与底部点击同步，离开音乐即停止试听。设置中的子页面不响应主页面横滑，不让滑块和日历选择被误切页。
- 设置中心作为 AI、历史、统计、导入导出、外观、提醒默认与权限入口；删除重复顶栏菜单入口，不删除功能。
- 外观支持系统/浅色/深色，森林、海蓝、紫罗兰、琥珀及自定义主色（#RRGGBB）；本地保存并随设置备份，校验输入。明暗表面、主色前景由统一规则派生，响铃页也使用同一主题。
- 日历支持周末/普通工作、官方放假、调休补班、自定义休/班、今日/选中视觉层级，文字标签和图例不只依赖颜色；显示已核对 2026 假期的名称。未知年份不推算官方放假。
- 设计：森林 #356859、雾白 #F7FAF7、墨色 #1B211E、休息色 #A0393D、补班蓝 #245F96；系统中文字体，标题24/正文15/说明12，明确分组，减少统一大卡片和装饰文案。

```
主页面 [提醒 | 音乐 | 日历 | 设置] ← 可横滑
设置中心 → 外观 / 提醒默认与权限 / AI / 数据 / 历史 / 统计
编辑器 [基本 | 重复 | 提醒点 | 音乐]
        当前区独立滚动
        [取消]                 [保存]
```

## C. 音乐元数据与响铃页

- 复用现有 Media3 无播放元数据读取，读取封面、歌名、歌手、专辑以及其可识别的内嵌歌词（ID3 USLT、Vorbis LYRICS、MP4 ©lyr）。不联网下载，不修改原文件，不申请整库存储权限。
- 延迟读取应用私有音频副本，IO 读取有超时、大小及图片解码尺寸上限，结果小型内存缓存；不把图片/歌词塞进 Intent 或数据库大列。
- 音乐详情可查看内嵌信息与歌词；响铃页显示当前会话歌曲封面和歌词。LRC 有时间戳则跟随实际播放位置高亮；无时间戳则可滚动查看原文。没有封面/歌词显示明确状态，兜底曲也可正常停止。
- 元数据提取失败只降级显示，不能让提醒播放失败；旧库无需重新导入。
