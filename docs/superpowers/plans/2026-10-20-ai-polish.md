# AI Connection and Interface Implementation Plan

> **Execution:** Follow this plan task by task using the tools available in the current Codex session. Steps use checkbox (`- [ ]`) syntax. Use `verification-before-completion` to report evidence; no additional execution skill is required.

**Goal:** 修复 DeepSeek 根地址连接并完善 AI 工作台、提醒首页与草稿的可读性。

**Architecture:** 保留现有单模块及 Repository 边界；在 AI 配置层统一解析实际地址，客户端处理安全诊断，ViewModel 保留可见结果。Compose 调整呈现，不迁移数据库。

**Tech Stack:** Kotlin、Jetpack Compose Material 3、HttpsURLConnection、JUnit、既有 Android instrumentation。

**Spec:** docs/features/2026-10-20-ai-polish.md

## Global Constraints

- 保持包名、Room 4、已有数据与现有依赖，不扩大到语音或图片识别。
- 不改变主机、不跟随重定向、不自动重试。
- 真机覆盖安装前备份 APK 与私有数据、全程无声。
- 不回显服务端原始正文、认证头或用户密钥。
