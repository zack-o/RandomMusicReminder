# 乐醒：产品体验重构 v2

2026-10-27。范围为产品结构、功能体验、视觉界面与交互规则。所有页面中的事件、歌曲、服务地址和统计均为演示内容。本轮不修改 Android 应用，不代表手机中的功能已经更新。

## 设计目标与方向

乐醒的核心是“为一件事，在合适的时间，用不同音乐提醒”。界面围绕事件、提醒点、声音和处理结果展开。首页回答接下来什么时候提醒；详情解释为什么在这个时间提醒；编辑器允许从任意分区直接保存；响铃页把结束和稍后操作放在最易找到的位置。

视觉采用雾蓝、冷白与深蓝文字，主要时间用大数字表达。日程用纵向时间线，普通设置用安静的行列表。较大的圆角用于主要信息面板，中等圆角用于输入和行容器，小圆角用于选项。唱片圆环是缺少封面时的统一占位图形，有封面时优先使用真实歌曲封面。无需装饰性渐变或持续运动。

## 全局结构

底部固定四个入口：**提醒 / 音乐 / 日历 / 设置**。主页面只通过点击切换，移除横向翻页手势。切换后保留各页的位置与筛选条件；离开音乐模块时停止试听。

创建/编辑事件分为 **基本 / 重复 / 提醒点 / 音乐**。这四个分区可点标签，也可左右滑动。每区独立记住滚动位置，顶栏、分区标签和保存操作保持可见。分区之间共享同一份草稿，不因切换而清空。

左右滑动仅限编辑器内容区域；输入文字、拖动滑条、滚动选曲、日期选择器、弹出面板和系统返回手势均优先处理自身动作。没有用滑动才能到达的唯一入口。原型包记录点击路线，真实双向滑动需在设计工具与后续产品中分别验证。

子页面返回上一级，不切到其他底部栏目。响铃页属于即时处理流程，结束后按场景返回原页面或事件详情。系统返回、关闭按钮与顶部返回使用同一套未保存规则。

## 提醒首页与事件管理

| 细节 | 目标体验 |
| --- | --- |
| 下一次提醒 | 显示最近的**实际触发时刻**和剩余时间，同时说明事件发生时间与提前量。例如09:50提醒，10:00开会 |
| 今天的清单 | 以事件发生时间组织，一件事保持一条主记录；展开或进入详情再查看多个提醒点 |
| 今天/全部/暂停 | 筛选只改变显示。暂停、恢复使用明确开关；暂停不删除历史 |
| 搜索 | 搜索名称和备注，保留当前筛选。无结果时可清除关键词或筛选 |
| 批量管理 | 点击“选择”进入模式，显示明确数量。跨筛选保留已选集合并提示隐藏的已选项；离开批量模式后清空选择 |
| 暂停/恢复 | 立即反馈目标状态和下一次安排；操作失败时恢复原状态并解释原因，不显示虚假的成功开关 |
| 跳过本次 | 先列出本次尚未发生的提醒点，确认后只跳过这一轮；后续重复不受影响。属于新增体验提案 |
| 复制事件 | 创建新草稿，保留参数，要求重新确认日期；不直接启用一份重复排程 |
| 删除事件 | 点明事件名称、数量和未来提醒影响；已记录历史保留其发生事实，不因为事件删除而伪造缺失 |
| 过去的一次性事件 | 从“下一次”排除，保留在完整清单供查看、复制或整理；不自动补响 |
| 空白状态 | 直接提供创建入口，并说明可以先导入音乐；不强制连续引导或权限申请 |

首页示例当前时间为09:41，下一次09:50，因此显示9分钟后。示例中的“今天2个事件”与日历中“2个事件、3个提醒点”分别使用事件数和提醒点数。

## 创建与编辑

### 基本信息

名称必填，备注选填。日期和时间明确写“事件发生日期/时间”。默认显示24小时制。时间可直接输入，日期有今天、明天等快捷入口。键盘弹出时保存按钮保持可达，字段滚动到可见位置。

编辑器提供常用默认值，普通单次事件无需逐个打开四个分区。保存前的核对页汇总发生时间、重复、提醒点、音乐和下一次有效触发时间。点击摘要可回到对应分区修改。

草稿保留是新增体验提案：离开时提供“保存草稿并离开 / 继续编辑 / 放弃修改”。草稿不会开始提醒，也不混入已启用事件。新建入口发现草稿时可继续或另建；编辑已有事件时保留原生效版本，直到用户保存。

### 重复规则

| 类型 | 交互与边界 |
| --- | --- |
| 单次 | 显示完整发生日期，不出现无关的结束日期和星期控件 |
| 每天 | 起始日期、当地时刻、可选日历策略、可选结束日期 |
| 每周 | 明确选择星期，至少一个；选择后立即更新未来几次日期 |
| 每月 | 根据开始日期的日号重复；没有该日期时可选跳过或当月最后一天。月末不会导致后续月份漂移 |
| 每年 | 根据开始日期的月日重复；2月29日使用同样的缺日策略。当前设计按公历表达 |
| 每N天 | 使用日历日间隔和开始日期锚点，显示未来几次实际日期；当地时间保持一致 |
| 结束日期 | 明确“包含结束当天”，按事件发生日判定；提前提醒可能出现在更早日期 |
| 日历策略 | “不使用”完全不受覆盖影响。每日/每周可按法定工作日替代星期限制；月/年/间隔先按规则匹配，再由日历过滤 |
| 未知年份 | 显示官方数据未收录，提供检查策略和日期的入口；不把普通周末推测包装为官方放假安排 |
| 时区变化 | 在规则摘要说明按当前当地时刻安排；返回应用后提示下一次时间已按当前时区更新。跨夏令时日期以预览核对 |

日期预览是目标体验提案，不等同现有应用已支持所有预览能力。农历、每月第N个星期几、按完成时间滚动等未纳入本轮默认规则；未来增加时需要独立定义，不能含糊套用现有类型。

### 提醒点

提醒点列表按实际触发时间排序，同时写提前量。0表示准时。分钟、小时、天使用清晰的数值与单位，避免只能输入大数字。新增时提供准时、提前10分钟、提前1天等快捷值；高级输入保留大提前量能力。

每条独立设置温和/强提醒、响铃时长和稍后选项。温和/强提醒以简短描述说明差别，不能承诺绕过系统静音或勿扰。时长使用秒/分钟可理解地表达；异常输入在原位置说明允许范围，不清空其他字段。

同一事件中的提醒提前量不得重复。保留至少一个有效提醒点。批量应用设置时逐项勾选“方式、时长、稍后”，展示影响数量，提前量保持原值。

保存前跳过已经过去的触发点，并明确展示“已过期，跳过”，同时保留未来有效提醒。若没有任何未来触发时间，核对页给出具体原因和修改入口，不以“已启用”掩盖没有未来安排的状态。

当前项目原有的32条提醒点、5～1800秒响铃、3650天提前上限作为输入边界保留在规格中；主界面不把极限数值当作常用选项铺满。

### 事件音乐

默认使用全局音乐池。选择专属歌曲时展示数量、可用性与勾选集合；全局停用和文件失效仍会影响实际可用性。切换范围不会删除音乐，也不悄悄清空用户之前的专属选曲。

音乐为空时仍可保存事件，但核对页必须写明使用备用提示音。展示“可选数量”和“实际可用数量”，避免把失效、停用曲目算成可播放。

## 音乐库与试听

| 细节 | 目标体验 |
| --- | --- |
| 导入 | 选择本地文件后显示处理中、已成功、重复跳过、失败的独立结果。失败可单独重试，不重复导入成功文件 |
| 文件边界 | 导入为应用内副本；不改原文件。删除按钮写“删除应用内副本”，说明受影响的事件与备用音后果 |
| 筛选 | 可用、全部、停用、失效可区分；筛选动作不改变歌曲状态 |
| 批量操作 | 显式进入选择模式，启用/停用只影响所选集合；与搜索、筛选分开 |
| 元信息 | 优先内嵌标题，缺失时用文件名；歌手、专辑、时长、文件大小各自有缺失状态 |
| 封面 | 内嵌封面失败使用统一圆环占位；不阻止试听或响铃 |
| 歌词 | 支持的内嵌歌词可查看；时间轴歌词提供跟随/自由滚动。没有歌词给简洁说明，不显示错误红条 |
| 试听控制 | 一次只播一首，播放/暂停/停止动作清楚。进度、起播位置、试听时长和应用内音量集中管理 |
| 试听结束 | 到时、离开音乐模块或应用进入后台时停止；切到模块内详情仍保留停止入口 |
| 音量 | 试听音量与真正提醒配置分开，百分比不等于实际声压，不自动修改系统音量 |
| 失效 | 暂不参与随机，提供重新导入有效副本的入口；替换关联需预览，其他可用曲目继续运行 |
| 随机规则 | 一轮内优先选未播放的曲目；换轮尽量避免与上一首连续重复。仅一首可用时，直说会重复 |
| 随机范围 | 全局池与事件专属选曲说明各自作用域。音乐加入、停用、失效时更新可用池，不伪造已播放历史 |
| 无可用歌曲 | 显示备用提示音，并在响铃记录解释原因；避免静默失败 |

画板中的演示歌词为本轮原创文字。设计不增加自动下载歌曲、自动补全歌词或联网抓取封面的行为。

## 响铃、通知与稍后

响铃页优先展示当前触发时间、事件名称、事件发生时间和提前量。正在播放曲目与自动结束倒计时位于其次。大按钮使用“结束本次提醒”，明确停止这一次响铃；不把它命名为“完成事件”。结束后说明下一次提醒是否仍在。

“稍后提醒”提供5、10、15分钟及当前默认选择，显示新的实际时间、已延后次数和剩余次数。每个原始提醒最多延后3次；达到上限时解释原因，仍可结束本次。

同一时刻多个事件合并为一次音乐播放，列出每个事件与提醒点，采用较强提醒方式和较晚结束时刻。稍后选择只覆盖明确选中的可稍后条目；不可稍后者说明原因。不把一个事件的按钮误用到同会话的所有事件。

通知与全屏页使用一致文案：事件名称、触发含义、结束本次、稍后。全屏受限时清楚显示通知呈现的能力状态，通知外观由系统决定。锁屏隐私、系统静音和后台限制在权限说明页解释，不伪称已经突破系统限制。

实际停止失败应保持可操作入口并说明原因，不能先显示“已结束”再继续出声。播放器异常、备用音失败、被新会话替换和自动超时分别进入可追溯历史。

## 日历与休班

月视图看日期分布，日程视图看事件列表，提醒时间轴看实际触发。跨日提前提醒列在触发当天，同时标注事件实际发生日。选中日与今日使用不同形状或边框，不能仅靠颜色区分。

官方放假、补班、普通周末、自定义休、自定义班分别有文字标签；官方数据附来源和年份。自定义覆盖优先显示为自定义，不抹去原始信息。恢复默认只清除所选日期的覆盖。

日历入口创建事件时预填所选日期；修改休班先展示会影响哪些启用日历策略的事件。未知年份单独提示，不自动认证官方假期。界面在无事件时给“为这天添加提醒”，而不是无说明空白。

## 设置与可访问性

设置中心按偏好、工具记录、数据分组。运行状态异常优先出现，并说明具体缺失能力。系统设置返回后刷新，授权失败或仍未授予时保留原提示。

外观支持跟随系统、浅色、深色、预设强调色与自定义色。选择时先预览；派生文字和按钮色确保可读，用户输入色值保留。响铃页使用同一主题。深色状态画板提供代表性验证，不能据此认定所有浅色页面已逐页转换。

默认提醒设置只影响之后新增的提醒点。修改已有事件通过编辑或明确批量操作完成。不会因为改变默认时长就改变已排程的所有事件。

设计以48的触控目标、24的页面边距和8的间距单位为基本准则。图标附语义标签；纯手势动作有按钮替代。屏幕阅读顺序与视觉顺序一致，报错与保存结果可被读出。

大字体时允许标题和说明换行，内容区滚动，关键按钮保持可达；长歌曲名与长事件名不会挤掉停止操作。减少动态效果时，保留状态变化但关闭不必要位移。本文是目标规格，全部字号组合与设备宽度仍需后续逐状态验收。

## 响铃历史与本地统计

历史支持日期、搜索、处理结果及测试筛选。详情展示计划触发、实际开始/结束、实际播放曲目、处理原因和关联事件。合并会话可展开多个提醒点；事件后续修改不改写已发生记录。

统计明确区分响铃会话数、关联提醒点数、稍后次数、测试次数与主界面使用会话。没有事件完成记录时不推导“完成率”。使用时长只统计本应用主界面，后台播放、其他应用和锁屏响铃不混入。关闭记录后停止新增使用数据，保留已有统计。

区间没有记录时说明范围和采集开关，不把缺失数据画成真实的零趋势。柱状图同时提供数值列表。AI解读仅发送用户确认的匿名汇总，原始事件、曲目和密钥不默认附加。

## AI助手

AI保持可选和默认关闭。入口集中到设置，提供输入、发送预览、结果草稿和确认写入四个阶段。输入支持手动文本及受支持文本文件；文件选择时说明类型、大小和编码要求。

发送确认页展示实际服务、完整请求地址、当前发送内容与使用目的。服务地址示例 `api.example.com` 仅为设计占位，不是真实连接。密钥不回显，不进入普通备份；配置保存不触发请求。手动测试也需要明确确认发送与可能费用。

生成结果逐条展示新增事件与重复规则；支持修改或取消单项。无法表达的规则明确标注，不能静默替换成近似规则。日期不明确时要求用户在草稿中补齐。无有效项、结果格式错误、鉴权失败、超时、离线和取消均保留原输入，不自动重试或切换服务。

连接页将地址、模型、密钥放在主层，高级参数折叠。兼容选项解释影响，供应商专用选项只在适用服务显示。现有密钥以“已保存，输入可替换”呈现。这里仅设计配置体验，本轮没有真实联网调用。

## 备份、恢复与撤销

导出先明确范围：核心JSON含事件、提醒点、自定义日历和设置；设置JSON仅含偏好；历史与统计通过CSV另行导出。普通JSON不含歌曲文件、AI密钥/连接配置和系统排程。保存前提示文件可能含个人安排，操作成功后说明文件位置或提供打开入口。

导入首先校验格式与版本，再展示新增、相同跳过、冲突和无法匹配音乐的条目。当前合并方向保留“只新增、保护已有数据”的约定。音乐需在本机唯一匹配，否则相应事件先跳过，用户可修正后再导入。重复导入不重复新增同样事件。

设置变化独立展示前后值、独立确认，默认不应用。不把数据合并和偏好应用混成含糊的一次“全部成功”。部分失败时展示各自结果，保留尚未完成项并允许重试。

**新增体验提案：按导入记录撤销。** 这与现有“导入前快照”分开设计。撤销前展示将删除的本次新增项、会取消的未来提醒、会保留的后续已修改项和可单独撤回的设置变化。无法确认的条目默认保留。撤销后给具体结果与未处理原因，不假装能无损回到任意历史时刻。

导入前快照继续可导出留存。重新合并快照遵守新增规则，不能把这种操作称为撤销。本轮只定义上述目标体验，未改动现有数据或恢复机制。

## 动效与反馈

主栏目点击切换采用克制的状态变化，不使用整页横向拖拽。编辑器页签响应用户滑动；底部面板轻量进入。倒计时与播放进度保持稳定，不持续闪烁或放大。保存、导入和发送进行时显示具体进行状态并防止重复提交；取消行为说明哪些结果已生效。

成功反馈说明动作与对象，例如“新增3个事件”“已停用2首”，并提供查看结果。错误反馈说明原因、保留内容和下一步。系统降级状态使用“受限/可能延迟”等准确词语，不显示“提醒正常”的成功色。

## 交付与边界

本目录包含本地Penpot格式包、每个画板的SVG/PNG、分模块总览、页面索引与评审清单。设计包中正文为独立的原生text对象，基础图形为rect/circle/path，另有点击路线、颜色库和文字样式。

Penpot在线页面此前被浏览器保存权限/管理策略拦截，本轮没有绕过该限制，也没有把新稿同步到在线文件。压缩包、引用、图层几何和预览可做本地核查；正式导入、原生字体回退、点击原型播放和编辑器滑动尚未完成工具内验证。相关验证结果见《评审与验证》。

当前方案覆盖现有主要功能和代表性异常分支，不等同所有屏幕、字体倍数、语言、年度日历和系统状态组合已穷尽。后续实现方案、性能、响铃可靠性与真机手势留到设计评审后再确定。
