# 评审与验证

2026-10-27。本轮是设计阶段。下文把本地文件检查、视觉检查和未来需要执行的产品验收分开记录。

## 本轮实际检查

- 本地Penpot包可作为ZIP正常读取，全部JSON可解析；文件、页面、父子图层、所属画板和点击目标引用已检查。
- 68个移动画板、2个视觉规范画板。原生正文为独立text对象，基础图形为rect/circle/path；无image类型整页截图图层。
- 每个画板各有一份PNG和SVG，共70份PNG、70份SVG。PNG可解码，SVG可作为XML解析。
- 文字框未超出所属画板；本地几何检查没有发现文字框相互覆盖。这个检查不能替代导入后的字体与换行复核。
- 点击路线目标存在，所保存热点的宽高均至少48。该检查没有模拟触控、手势或原型播放。
- 抽查浅色正文、辅助文字、主按钮、强调文字、深色正文/按钮及错误提示的对比度。八组样本最低为4.63:1；不是全应用可访问性认证。
- 示例日期与星期核对；每日统计样本2、4、3、5、4、6、4之和为28，与标题汇总一致。
- 本目录Markdown中的本地文件链接逐条检查，原有应用文件和此前设计稿不覆盖。

结构检查的逐项结果、当前图层数、点击路线数量和设计包SHA-256见 [verification-report.json](verification-report.json)。

## 视觉检查与修正

已查看主要流程与补充流程的分组预览。校对中修正了勾选符号缺字、中文误用数字字体、部分文字框过宽、首页计数与日历口径不一致、数字行高干扰下一行、单选/多选视觉不一致等问题；删除音乐与离开未保存内容拆成独立页面。

新版把设置中的运行提示改为与权限缺失场景一致；把AI发送页的设计占位说明改为可核对的演示请求地址；按本次导入撤销新增内容与导出旧快照分开呈现。

## 后续产品验收情景

以下是设计评审后的验收要求，不是本轮已经运行的测试。

| 场景 | 应看到的结果 | 关联画板 |
| --- | --- | --- |
| 主页面横向拖动 | 不切换底部栏目，竖向清单照常滚动 | 首页、音乐、日历、设置 |
| 创建页左右滑动 | 四分区顺序切换，同一草稿保留，系统返回与滑条不抢手势 | 基本、重复、提醒点、音乐 |
| 最短创建路径 | 只填名称与事件时间即可核对保存，常用默认值可理解 | 基本、保存前核对 |
| 离开未保存事件 | 可保留草稿、继续编辑或放弃；草稿不响铃 | 离开未保存内容 |
| 提前提醒跨天 | 同时写实际触发日期与事件日期 | 提醒点、提醒时间轴 |
| 提前量重复 | 保留输入，标出重复项与修正入口 | 创建校验与修正 |
| 月末缺日 | 跳过与取月末两种策略清楚，之后月份仍回原日号 | 复杂重复 |
| 每年2月29日 | 非闰年的处理与未来发生日期可核对 | 每年与缺日 |
| 每N天跨月 | 以开始日锚定，不累积日号漂移 | 每N个日历日 |
| 日历未知年份 | 明确未收录，提示策略与后果 | 日历策略、日期与休班 |
| 修改日历覆盖 | 原始信息保留，自定义单独标记；不使用策略的事件不受影响 | 日期与休班 |
| 音乐批量停用 | 只改变已选曲目，其他筛选下未选曲目保持原样 | 音乐批量管理 |
| 全局/专属选曲 | 明确可用数量，切换不丢此前选择 | 创建音乐范围 |
| 音乐库仅1首 | 说明可能重复，不承诺每次不同 | 随机规则 |
| 音乐失效或全空 | 备用音可理解，显示修复入口，历史说明原因 | 停用与失效、空白音乐库 |
| 导入部分成功 | 成功项保留，失败单独重试，重复项不重复添加 | 音乐导入结果 |
| 歌词缺失/读取失败 | 保留控制和播放能力，不将其当作响铃失败 | 曲目详情、歌词 |
| 离开音乐模块 | 试听停止，不会在旧请求返回后再次发声 | 试听控制 |
| 同时到时的事件 | 一次会话列出多件事，一首音乐，操作范围明确 | 多事件合并、合并历史 |
| 结束本次提醒 | 及时停声，后续提醒规则保留，反馈不声称事件完成 | 单事件响铃、结束反馈 |
| 达到稍后上限 | 不再提供可执行延后，说明次数，仍可结束 | 稍后提醒 |
| 无全屏能力 | 通知仍有一致的结束/稍后入口，状态准确 | 通知中的提醒、运行状态 |
| 系统授权后返回 | 刷新真实状态，失败时不显示成功 | 权限说明 |
| 改默认值 | 仅之后的新提醒点使用新值 | 默认值 |
| 改主题/大字体 | 主界面与响铃一致，按钮可达，长标题不遮挡 | 深色、大字体、外观 |
| 空统计区间 | 显示缺少数据的原因，避免画出虚假的零趋势 | 本地统计、统计偏好 |
| AI发送前取消 | 不发请求，输入保留 | 发送确认 |
| AI超时/格式错误 | 不写入事件，输入保留，手动决定重试 | AI失败、草稿核对 |
| AI配置只保存 | 不发送测试请求，密钥不进入导出 | AI连接 |
| 导入高版本/损坏文件 | 写入前停住，原数据不变 | 无法读取文件 |
| 数据导入与设置变化 | 分别预览和确认，显示各自结果 | 导入预览、设置独立确认 |
| 撤销本次导入 | 列出具体新增项，默认保留后续已编辑项 | 撤销导入影响预览 |
| 重复执行导入 | 相同事件跳过，无含糊重复新增 | 导入预览、结果 |

## 评审时优先决定

1. 雾蓝、时间线和唱片占位图形是否适合乐醒的气质。
2. “事件时间/提醒时间”的分离是否足够直观，保存核对是否值得保留。
3. 草稿、跳过本次、未来日期预览、失效歌曲关联修复和按清单撤销导入的优先级。
4. 进入实现前，在Penpot中完成一次导入、中文字体统一、关键路线播放与编辑器滑动验证。
