# 乐醒 0.8.0 开发验收

开发开始：2026-10-27；交付材料整理：2026-10-28（北京时间）。Android开发测试版，versionCode 8；应用包名保持不变。功能在原项目内增量修改，没有安装或升级依赖，没有提交或推送代码，没有向真实AI服务发送请求，也没有安装到手机。

## 本轮交付

1. 时间方式新增“固定时间 / 时间窗随机”。窗口包含两端，以分钟为单位均匀选择一次主提醒；重复窗口独立选择，可能连续相同。音乐仍独立洗牌。跨午夜明确选择次日，按开始日判断重复、假期和结束日期。
2. 首次进入已开始窗口默认跳过，可明确使用下一完整分钟以后的剩余时间。随机选择保存在本机排程，时钟/时区变化和重排不补抽。终态记录不被清理；删除原固定提醒点前转移随机记录，防止级联删除后重复响。
3. 随机主提醒默认无稍后、无补充。主动启用补充时，末分钟最多补充一次，主提醒恰在末分钟则合并。停止声音保留补充；响铃页、通知和详情的明确起床确认只取消本次待触发补充，未来窗口继续。
4. 晨蓝默认主题、首页搜索/筛选/下一项安排/详情核对、窗口范围与已选时刻分开显示；主页面移除横滑，提醒编辑器四区支持横滑与独立滚动。保留已保存的配色。
5. AI支持创建草稿、所选修改、排程解释、可能冲突、所选音乐元信息建议、导入提示解释和匿名统计解读。最多20组连接，按档案和实际接收地址隔离Key，保存/切换不联网；所有请求先核对全文、目标、模型再确认。
6. 所选修改支持标题、启停、时刻、窗口结束/跨日、时长与稍后。先列旧值/新值，写前重新校验，任何一项冲突就整批拒绝；成功操作保存本机撤销记录。撤销也保护后续手动修改。新建草稿沿用只新增合并与导入前恢复材料。
7. Room 5→6仅新增字段和AI操作表；旧schema1～5保留。JSON版本3兼容读取1/2，普通备份不含Key、种子、已选时间或系统排程。历史和统计CSV补充窗口来源与选定时间摘要。

随机模式的候选选择与规则计算在后台执行。系统投递迟到的原始随机实例允许60秒调度宽限，超过后记遗漏，不在窗口内重新抽签；播放入口也检查迟到，避免绕过整体重排。固定提醒原有遗漏语义保留；同刻随机已过期时，仍有效的固定提醒可继续。

## 边界与尚未验证

- 未进行手机覆盖安装、实际出声、锁屏唤醒、Doze、重启、蓝牙/勿扰和厂商后台保活测试；模拟器通过不能替代这些检查。
- 未调用真实第三方API；模型权限、区域、账单、输出质量和不同服务参数兼容性尚未验证。服务预设来源及核对日期见README。
- 音乐建议仅使用明确勾选的曲名和时长等元信息，不读取或上传音频，不自动改音乐池；排程解释和冲突判断只含所选事件及最多200个已安排实例，不能证明真实送达或实际声音重叠。
- AI重复规则/音乐池修改继续通过编辑器；新增草稿当前不提供一键撤销，使用导入前恢复材料。只有已应用的所选修改进入撤销记录，生成失败在页面反馈，不保存原始响应或密钥。
- 本轮将设计中的功能状态整合到原生页面与对话框，没有把109个Penpot画板逐一建成独立页面。部分更复杂的交互可在实机体验后继续细化。
- 没有证据证明随机时间能防止大脑过滤闹钟；功能只提供时间变化，不判断睡眠阶段、不承诺唤醒改善。
